📊 DashConnect

🚀 Overview

The JavaScript API Dashboard is a single-page web application that displays live data from multiple public APIs.

Each section functions as a mini app that fetches real-time data and dynamically updates the DOM.

This project demonstrates:

Asynchronous JavaScript (async/await)

Fetching data from third-party APIs

DOM manipulation

Event handling

Basic error handling

Dynamic content rendering

🧱 Features

The dashboard includes the following API integrations:

🐶 Random Dog Image

🐱 Random Cat Image

☀️ Weather Information

💱 Currency Exchange Rates

🎬 Trending Movies

🧑‍💻 GitHub User Data

🤣 Random Joke Generator

📈 Stock Market Information

Each section includes a button that triggers an API request and updates the page dynamically.

⚙️ How It Works

The page loads and JavaScript waits for the DOM to be ready.

When a button is clicked, an event listener triggers an asynchronous function.

The function uses the Fetch API to request data.

The response is converted to JSON.

The DOM is updated dynamically using JavaScript.

Basic error handling displays messages if a request fails.
